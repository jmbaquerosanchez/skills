# Matt's skills are copied, pinned to one commit

The kit carries copies of Matt Pocock's skills, taken from one commit of `mattpocock/skills`, instead of having projects install them from his repo. In three weeks he renamed `CONTEXT.md` to `GLOSSARY.md`, deleted `resolving-merge-conflicts` and moved skills between folders: a project installing from his repo gets his latest, and the flow can break with nothing to warn it. The copies still read `CONTEXT.md`.

So bringing the copies up to date is not done in passing, however obvious it looks. Porting a later change of his is a separate, deliberate decision, which starts from the commit in the copy's row of [skills/UPSTREAM.md](../../skills/UPSTREAM.md).
